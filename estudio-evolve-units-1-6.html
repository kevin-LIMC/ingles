Writing — plantilla y práctica

En el examen sueles tener un texto corto (email, post, review, opinion). Estructura: introducción → ideas con conectores → conclusión.

Conectores útiles (B1)

  • First / Firstly, … Then / Next, … Finally, …
  • However, … / Although …, … / Because … / So …
  • In my opinion, … / I think … / I would suggest …

Prompt de práctica

Write an email to a friend (120–150 words). Invite them to an event next weekend, explain why it will be fun, and ask them to reply.

Listening — técnica + dictado ligero

  • Antes de escuchar: lee las preguntas; subraya palabras clave (nombres, números, verbos).
  • Primera escucha: idea general (gist). Segunda: detalles.
  • Atención a numbers, dates, prices, names y a palabras de reformulación (actually, I mean, in other words).
